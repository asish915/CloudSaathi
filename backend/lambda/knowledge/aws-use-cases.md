# AWS Service Use Cases
EC2: long-running applications requiring operating-system control.
S3: backups, static assets, data files and build artifacts.
Lambda: event-driven APIs and automation.
API Gateway: public HTTP APIs.
RDS: applications requiring managed SQL databases.
ECS/EKS: containerized applications.
Bedrock: generative AI applications using foundation models.
CloudFront: content delivery and caching.
